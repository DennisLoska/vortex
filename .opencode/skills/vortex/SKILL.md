# Vortex

PixiJS v8 app. Each project in `projects/<name>/` is a self-contained media composition.

## Project Structure

```
projects/<name>/
  project.json       ← config: { "language": "EN" | "DE" }
  backgrounds/       ← images (PNG/JPG/WebP) for background layer crossfade
  assets/            ← images + videos (PNG/MP4) for random spawn pool
  texts/             ← numbered .txt files (01_intro.txt, 02_scene.txt)
```

## Add New Project

```bash
bash .opencode/skills/vortex/new-project.sh <name> [EN|DE]
```

Then populate media files into each directory. AssetPack processes them on next `npm run dev` or `npm run build`. Hotkeys 1-9 auto-discover the new project at next screen load.

## Key Architecture

- **`projects/`** — all project dirs (gitignored), processed by AssetPack into `public/assets/`
- **`projects/main{m}/`** — global UI (spritesheets, logo) — NOT per-project
- **`projects/preload{m}/`** — preload logo — NOT per-project
- **AssetPack** — `pixiPipes` with `resolutions: { default: 1 }` (no 0.5x variants)
- **Project discovery** — `CompositionScreen.ts` reads manifest, extracts unique top-level path segments
- **Switching** — key 1-9 → full reload (`hide()` → `prepare()` → `show()`)

## Manifest Rules

`src/manifest.json` is auto-generated by `scripts/assetpack-vite-plugin.ts`. It registers only **images** and **videos** for PixiJS `Assets.init()`. Text and voice files have independent loading paths.

| Asset type | Loaded via | Manifest entry? |
|------------|-----------|----------------|
| Background images/videos | `getProjectBackgrounds()` → `Assets.load()` from manifest | ✅ Yes |
| Spawn pool images/videos | `getProjectAssets()` → `Assets.load()` from manifest | ✅ Yes |
| Text files (.txt) | `TextOverlay.ts` → `import.meta.glob` | ❌ No (excluded from generator) |
| Voice files (.wav/.mp3) | `TextOverlay.ts` → `import.meta.glob` | ❌ No (excluded by file extension) |

**When adding project media:**
- **Images/videos** in `backgrounds/` or `assets/` → just place files; rebuild regenerates manifest
- **Text files** in `texts/` → place numbered `.txt` files; `import.meta.glob` picks them up automatically
- **Voice files** in `voices/` → place `.wav/.mp3/.m4a/.ogg` with matching numeric prefix; `import.meta.glob` picks them up
- **Do NOT manually edit `src/manifest.json`** — it's overwritten every build

## Key Files

| File | Role |
|------|------|
| `scripts/assetpack-vite-plugin.ts` | AssetPack Vite plugin, entry `./projects`, generates manifest |
| `src/app/assetManifest.ts` | Manifest query functions: `getProjectNames`, `getProjectAssets`, `getProjectBackgrounds` |
| `src/app/screens/main/CompositionScreen.ts` | Screen orchestrator, project switching |
| `src/app/screens/main/composition/BackgroundLayer.ts` | Background crossfade, filters by `${project}/backgrounds/` |
| `src/app/screens/main/composition/AssetSpawner.ts` | Random spawn pool, filters by `${project}/` |
| `src/app/screens/main/composition/TextOverlay.ts` | Text overlay, loads from `/projects/${project}/texts/` via `import.meta.glob` |
